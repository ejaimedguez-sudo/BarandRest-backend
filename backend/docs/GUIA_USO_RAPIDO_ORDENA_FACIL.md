# Guia Rapida - Ordena Facil

Esta guia esta pensada para que cualquier persona pueda operar el sistema en pocos minutos.

## Flujo recomendado

1. Elegir rol operativo en la parte superior de la portada.
2. En el menu izquierdo, usar la busqueda para encontrar la opcion.
3. Hacer clic en la opcion para cargar su vista en el panel central.
4. Si necesitas ayuda, usar el boton `Iniciar tutorial` en la guia lateral.

## Menu lateral

- `Mostrar todas las opciones`: enseña el catalogo completo del sistema.
- `Solo opciones permitidas`: muestra un menu reducido segun rol.
- `Restablecer`: devuelve el panel lateral a su configuracion inicial.
- `Plegar menu`: oculta o muestra el panel para ganar espacio.

## Navegacion basica

- Atajo `/`: enfoca automaticamente la busqueda de menu.
- `Recargar Dashboard`: refresca la vista central actual.
- `Abrir vista actual`: abre el contenido central en una pestana nueva.

## Herramientas avanzadas

Las herramientas avanzadas estan ocultas por defecto para simplificar el uso.

- `Mostrar herramientas avanzadas`: abre acciones tecnicas.
- Requieren permisos por rol y en algunos casos API Key.

## Recomendaciones de operacion

- Para personal nuevo: activar tutorial y usar `Solo opciones permitidas`.
- Para supervisores: usar `Mostrar todas las opciones` para revisar modulos.
- Si el panel se ve raro: usar `Restablecer`.
